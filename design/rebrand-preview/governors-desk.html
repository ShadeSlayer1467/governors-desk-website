Proposed README introduction

The Governor’s Desk

Less routine work. More time for your kingdom.

A Windows desktop automation companion for KingShot players using MuMu Player. Organize your cities, configure recurring work, and follow what the application is doing from one place.

Supports routine training, Arena and Intel workflows, with Pet Adventures undergoing live validation. Some workflows need supervision; unfamiliar screens and recovery scenarios remain limitations.

Independent project; not affiliated with or endorsed by KingShot. Automation may violate game rules. The name makes no claim of permission or account safety.

Local mock rebrand · Original visual concept; the application rename is maintained separately · No external assets, fonts or network requests.
